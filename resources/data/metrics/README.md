# Product Metrics Guide

## Overview
Metrics are quantifiable measures used to evaluate product performance and user behavior. Key metrics guide product decisions and measure success.

**Created by:** Ankit Saxena | **Purpose:** Educational Resource

---

## Key Product Metrics

### User Metrics
- **DAU**: Daily Active Users
- **MAU**: Monthly Active Users  
- **New Users**: New signups
- **Returning Users**: Users who come back

### Engagement Metrics
- **Session Length**: Time spent per session
- **Session Frequency**: Sessions per user
- **Feature Adoption**: % using new features
- **Stickiness**: DAU/MAU ratio

### Retention Metrics
- **Retention Rate**: % users returning after day 1, 7, 30
- **Churn Rate**: % users leaving
- **LTV**: Lifetime value per user
- **Payback Period**: Time to recover CAC

### Growth Metrics
- **CAC**: Customer Acquisition Cost
- **MRR**: Monthly Recurring Revenue
- **Growth Rate**: Month-over-month growth
- **Viral Coefficient**: User referral rate

---

## AARRR Framework

- **Acquisition**: Getting users
- **Activation**: First value moment
- **Retention**: Bringing users back
- **Revenue**: Monetizing users
- **Referral**: Users inviting others

## Measuring Metrics

1. Define goal
2. Choose metric
3. Set targets
4. Track regularly
5. Analyze trends
6. Take action
7. Iterate
