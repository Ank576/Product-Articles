# Product Management Checklists

## Overview
Actionable checklists for key product management activities. Ensure nothing is missed and maintain consistency.

**Created by:** Ankit Saxena | **Purpose:** Educational Resource

---

## Checklist Types

### PRD Launch Checklist
- [ ] Define problem statement
- [ ] Research user needs
- [ ] Competitive analysis done
- [ ] Success metrics defined
- [ ] Resources allocated
- [ ] Timeline established
- [ ] Stakeholders aligned
- [ ] Design reviewed
- [ ] Development estimated
- [ ] QA plan ready
- [ ] Go-to-market ready

### Feature Release Checklist
- [ ] Feature specs documented
- [ ] Design approved
- [ ] Development complete
- [ ] QA tested
- [ ] Bugs fixed
- [ ] Documentation ready
- [ ] Support trained
- [ ] Marketing prepared
- [ ] Analytics setup
- [ ] Rollout plan ready
- [ ] Monitoring active

### User Research Checklist
- [ ] Research questions defined
- [ ] Participants recruited
- [ ] Interview guide ready
- [ ] Sessions scheduled
- [ ] Recordings setup
- [ ] Sessions conducted
- [ ] Notes compiled
- [ ] Themes identified
- [ ] Insights documented
- [ ] Findings shared

### Product Launch Checklist
- [ ] Public beta launched
- [ ] Feedback collected
- [ ] Issues addressed
- [ ] Documentation complete
- [ ] Sales trained
- [ ] Support ready
- [ ] Marketing campaign live
- [ ] PR outreach done
- [ ] Community engaged
- [ ] Analytics tracking
- [ ] Post-launch review

---

## Using Checklists

1. Select relevant checklist
2. Customize for your context
3. Share with team
4. Track progress
5. Complete all items
6. Review and iterate
